# 1-stud kit: how to use

1. Create a new project and upload everything in this folder (keep the folder structure: `src/`, `export/`, `skills/`).
2. Open a chat in that project and say what you want, for example:
   "Build a 60×60 desert canyon with a ruined tower as the landmark. About 6k parts."
3. The assistant reads `CLAUDE.md` and `skills/one-stud/*`, asks a few questions, then builds in stages (blockout, trees and ground, props, polish) and waits for your OK after each.
4. Each stage has a preview page (`... .dc.html`) with view buttons, a Textures toggle and a Player toggle. The download button gives an `.rbxmx` to insert in Roblox Studio.

Finished examples to open first: `Oak Glade Dressed.dc.html`, `Snow Camp Dressed.dc.html`, `Sandy Plateau.dc.html`, `Oak Trees.dc.html`, `Flowers v2.dc.html`.
